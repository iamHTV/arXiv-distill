# [2610.25540] Auditing Tool Traces in Agentic LLMs: Source Localization và Counterfactual Dependence Testing

## Problem
- Agentic LLM pipelines (tool use / RAG / chained tool returns) có evaluation failure mode mà benchmark checks thường miss: serialized tool results chứa HIDDEN LABEL SHORTCUTS — entry identifiers, version strings, file paths, duplicated fields, template artifacts — correlate với labels mà KHÔNG mang intended scientific semantics (từ deposition, annotation, sampling, serialization). Shortcuts survive semantic data splits vì generating process của identifier không follow scientific grouping. Screen concatenated tool trace cũng miss pattern giới hạn trong 1 component vì heterogeneous results dilutes nó (dilution effect). Kết quả: performance "rigorous" có thể là shortcut exploitation chứ không phải evidence-grounded reasoning. Gap: chưa có method tách (a) shortcut nằm ở tool result nào + (b) frozen LLM có thực sự phụ thuộc shortcut đó không.

## Contribution
- Two-stage audit tách source localization khỏi behavioral verification:
  - Stage 1 — PT2D (Per-Tool TF-IDF Decomposition): audit MỖI tool section riêng biệt (TF-IDF + balanced logistic regression), chỉ giữ concatenated trace để so sánh → khắc phục dilution.
  - Stage 2 — Token-Class Redaction: trace suspect source + substrings về serialized fields, group thành token classes, redact toàn bộ class trong mọi prompt-bearing field, RE-evaluate frozen LLM (counterfactual, no retraining) → kiểm tra model dependence.
- Dilution validation: real tool-subset sweeps + synthetic label-independent additions.
- Case study overturn: apparent evidence-grounded generalization (AUROC 0.8136 vs 0.4928 baseline) thực ra là PDB identifier shortcut — redact identifiers → chance.

## Method (tóm tắt cốt lõi)
- Setup: Dfit/Deval audit partitions aligned với eval protocol (split-agnostic); example (xi, yi∈{0,1}, Ei=[e(1)i..e(T)i]) — tool trace = ordered serialized tool results (KHÁC với reasoning trace do LLM tự sinh).
- Stage 1: scope s ∈ {full, 1..T}: TF-IDF ϕs (word 1–2-grams lexical + char 2–5-grams + char 3–5-grams identifier fragments), balanced logistic regression gs trên Dfit, score Deval → AUROC As. Rank carriers bằng compare At vs full-trace scope, chance, other tools — KHÔNG có universal threshold. Không LLM retraining, không parameter access. Associational evidence (pattern predictive ≠ LLM dùng).
- Stage 2: group suspect values cùng generating semantics → candidate token classes (entry identifiers, version strings, file-path components); target COMPLETE class (isolated n-gram cover chỉ phần shortcut); redact class c = replace mọi occurrence trong ALL prompt-bearing fields bằng class-specific placeholder, preserve labels + reference answers; global replacement ngăn duplicated values sống sót; test 1 class/lần tại frozen checkpoint → ∆Ac = Aorig − ARc (positive = mất performance). Non-overlapping recurring classes làm controls.
- Case study: TCR–pMHC binary binding, dataset Slone et al 2025 + peptide-disjoint cluster splits Abeer et al 2026: cluster 0 = 12,940 train (3,483 pos) + 1,438 val (397 pos); clusters 1–5 = 4,898 test (264 pos). Model Qwen3-4B SFT trên task fields + complete 5-tool trace. 5 tools fixed order: (1) CDR3β biophysical descriptors (length/composition/charge/flexibility/contact potential); (2) McPAS-TCR retrieval + similarity; (3) ThermoMPNN mutation-level ∆∆G; (4) CDR3β positional stability + hotspots từ (3), adapted from Biomni; (5) structure-based interface descriptors (buried surface FreeSASA, contact distance, H-bonds, salt bridges). Tools nhận candidate fields + modeled complex, KHÔNG BAO GIỜ nhận labels.

## Key Findings
- Fine-tuned Qwen3-4B: Aorig = 0.8136 test AUROC (joint clusters 1–5) vs label-balanced no-evidence baseline 0.4928 (dev comparison) — at face value evidence-grounded generalization.
- PT2D full-trace scopes near chance: Afull = 0.4818 (word 1–2), 0.4677 (char 2–5), 0.4876 (char 3–5) → full-trace screening says "little leakage" (FALSE NEGATIVE). Per-tool decomposition reverses: Tool 3 (predict-thermompnn-ddg) A3 = 0.6288 / 0.6365 char features; Tool 5 (cũng serialize PDB ID) weaker A5 = 0.5259–0.5310; Tools 1, 2, 4 near chance. Gap A3 − Afull = 0.1489 (char 3–5-grams) → aggregation hides strong local signal.
- Regression weights localize signal từ Tool 3 đến PDB-ID fragments trong ThermoMPNN_inference_<pdb_id>.csv: word features Tool 3 chance (A3 = 0.4946), char features 0.6365 — signal là identifier fragments KHÔNG phải biological language; prefixes "_21" favoring binders, "_17" favoring non-binders; two-digit PDB-prefix lookup AUROC 0.6967 → motivates complete PDB-ID redaction.
- Dilution sweeps: progressive append Tools 1, 2, 4, 5 vào Tool 3 → char 3–5-gram diagnostic AUROC giảm monotonic 0.6365 → 0.4876; synthetic label-independent additions reproduce decay, reach chance tại K=5 → explains full-trace false negative, motivates per-tool decomposition.
- Frozen-checkpoint redaction (Table 1): Original 0.8136; PDB-ID redacted 0.4972 → ∆APDB = +0.3163 (collapse nearly all above-chance ranking → chance); Peptide redacted 0.8152 → ∆Apeptide = −0.0017 (control STABLE — rules out literal epitope sequence reuse). Combined: behavior in TCR task depends on dataset-specific identifiers, không phải intended biological evidence.

## Actionable Insights
- "Agent dùng evidence" có thể chỉ là identifier pattern-matching: tool augmentation trông tuyệt (0.81 vs 0,49 baseline) nhưng xóa PDB IDs → collapse 0,50. Ví dụ: trước khi tin agent RAG/hỗ trợ khách hàng "vận dụng retrieved data", redact suspected identifier classes (order IDs, ticket IDs, template tokens) trong tool outputs rồi re-run — accuracy collapse = shortcut-matching, không reasoning.
- Screen MỖI tool result riêng, KHÔNG screen concatenated trace — dilution hides shortcuts: full-trace TF-IDF ≈0,48 (chance) trong khi single carrying tool 0,64 (gap 0,1489; monotonic decay 0,6365→0,4876 khi append tools; synthetic decoys reproduce). Ví dụ: agent 4 tools (search + CRM + calculator + scraper) — chạy diagnostic TF-IDF + logistic regression PER TOOL OUTPUT FIELD, không tin whole-trace screening.
- Word/char n-gram split fingerprint shortcut TYPE: word chance (0,4946) + char 2–5 spike (0,6365) → signal trong identifier fragments; top fragments ("_21" binders, "_17" non-binders, prefix lookup 0,6967) chỉ rõ WHICH serialized field cần sanitize. Ví dụ: audit tool outputs agent — char-ngram spike localizing vào filename/ID pattern = anonymize field đó ngay.
- Redaction protocol CẦN control class: peptide redaction ∆A −0,0017 (stable) validates PDB collapse là specific, không phải generic redaction damage. Ví dụ: luôn redact 1 non-overlapping control class cùng suspect class — drop mà không có stable control chứng minh nothing.
- Detection rẻ + model-agnostic: Stage 1 TF-IDF + balanced logistic regression chỉ — no LLM retraining/parameter access, works on frozen checkpoints. Ví dụ: production agent pipeline auditable: diagnostic classifier per tool result + frozen re-eval placeholders — triển khai trong CI trước khi công bố benchmark gains.

## Assumptions & Limitations
- Điều kiện: cần labeled audit partitions aligned với eval protocol; tool results serialized thành text (serialization choices bản thân có thể tạo artifacts); Stage 2 cần frozen checkpoint + identical generation/parsing/scoring pipeline.
- Paper thừa nhận: PT2D evidence associational — predictive text pattern need not be used by downstream LLM; redaction may remove correlated signals or shift input distribution → conclusion limited to model behavior; short-prefix attribution comes only from PT2D weights (redaction supports dependence on complete class); targeting complete class vì isolated n-gram covers only part of shortcut-bearing value.
- [MY OWN]: single domain (TCR–pMHC), single model (Qwen3-4B), single SFT run — generalization sang other agents/domains unproven; logistic regression diagnostic là LINEAR — non-linear shortcuts có thể evade (char-n-grams partly compensate); peptide-disjoint splits đặc thù biological benchmark; "chance" context binary ~0.5 — multi-class task cần chance baseline appropriate; numerical separators/serialization conventions differ per toolchain → token-class definition cần domain knowledge; paper workshop (AgenticLS, NeurIPS 2026) không full peer review.
