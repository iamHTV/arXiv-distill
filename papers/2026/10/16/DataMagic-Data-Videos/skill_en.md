# Skill: datamagic-declarative-multi-agent-data-videos
Source: 2609.33403v1
Type: framework

## When to use this skill
- Authoring data videos for a business or individual.
- Want to automate data video creation from raw data.
- Need to reduce time and cost of creating data videos.

## When NOT to use
- No raw data to create videos from.
- Only need static videos, no need for dynamic charts and animations.

## Required input
- Raw data to create data videos.
- A declarative multi-agent system for authoring data videos.
- Video data templates to reference.

## Steps
1. Collect raw data to create data videos.
2. Build a declarative multi-agent system for authoring data videos, with agents responsible for different roles (planner, coordinator, etc.).
3. Use declarative specification to structure the data video (charts, narration, animations).
4. Run the system to automatically create data videos.
5. Evaluate data video quality (content quality, execution rate, creation time).

## Expected output
- Data video quality: 3.89/5 (+83% vs direct generation methods).
- Execution rate: above 95%.
- Video creation time: reduced by 79.7% (from 39.2 to 8.0 minutes).

## Example application
Solopreneur making sales data video: collect raw sales data, use DataMagic to automatically create data videos with dynamic charts, voice narration, and synchronized animations. Reduce video creation time from 39.2 minutes to 8.0 minutes, quality from 2.13/5 to 3.89/5.

## Gotchas
- Need raw data to create data videos; no data, no video.
- Need declarative multi-agent system; don't use static visualization tools.
- Need to evaluate data video quality after creation to ensure accuracy and attractiveness.
