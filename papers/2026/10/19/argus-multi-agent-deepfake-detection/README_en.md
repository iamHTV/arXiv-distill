# 2608.06865v1 Multi-Agent Forensic Reasoning for Generalizable Deepfake Video Detection (ARGUS)

## Problem
- New generative AI (Seedance 2.0, Sora 2, Kling...) synthesizes entire faces with stable identity and plausible motion → detectors trained on earlier techniques suffer substantial degradation on unseen methods.
- Conventional detectors (small vision models) learn from binary real-or-fake labels → rely on shortcut features specific to datasets/generators → fail on new forgery methods, identities, compression conditions, data sources.
- Existing benchmarks: limited coverage of the synthesis landscape + only binary labels without visual evidence → coarse-grained supervision makes it hard to learn subtle cues and to tell whether a detector has acquired transferable forensic knowledge or merely fitted dataset biases. Authenticity decisions without supporting evidence limit trustworthiness and auditability in high-risk settings.
- Single MLLMs (multimodal LLMs) are unreliable: they overemphasize the most salient appearance cue, overlook weak evidence spread across frames, or generate plausible explanations inconsistent with the final verdict. Holistic judgment ignores the distinct causes of different forgery traces: texture over-smoothing, inconsistent illumination, unstable motion, physical plausibility violations — each requires different forensic knowledge.

## Contribution
- FaceVid-Forensics-100K: 100,000 videos (21,075 real + 78,925 fake), 33 synthesis methods across face swapping (FS), face reenactment (FR), entire-face synthesis (EFS: T2V, I2V, TI2V, V2V), including recent generators such as Seedance 2.0. vs prior datasets (DF40 23 methods, Celeb-DF++ 22, DeepfakeDetection 5): largest + the only one with fine-grained textual labels (Observations + Explanations).
- Fine-grained textual supervision on 4 dimensions: texture, lighting, motion, physics — observations + verdict-consistent explanations, auto-synthesized through a multi-model aggregation and conflict-resolution pipeline.
- Multi-agent forensic reasoning framework: 4 specialized domain-expert agents (texture, lighting, motion, physics) independently analyze forgery cues; a judge agent reconciles reports → final prediction + explanation.
- OOD evaluation: the entire framework uses small open-source MLLMs (Qwen2.5-VL-7B base) yet outperforms all methods including closed-source GPT and Gemini models, ranking first across all reported metrics.

## Method
- Dataset collection: AIGVDBench (~442,000), GenVidBench (~6,780,000), ViF-Bench (~3,000), FF++ (~5,000) + 2,901 crawled Seedance 2.0/recent videos (577 retained after manual screening). Face detection pipeline filters frame-by-frame → 1,158,585 valid face-centric videos (30,240 real + 1,128,345 fake, 436.56 hours). Real deduplicated by YouTube ID → 21,075. Hard-sample prioritization: 4 dominant generators (ModelScope, Pika, Text2Video-Zero, VideoCrafter2) evaluated with the AltFreezing detector, prioritizing retention of low scores (harder to distinguish): 235,007→11,958 / 75,471→15,163 / 435,210→10,432 / 376,471→32,690 → fake total 78,925.
- Splits: train ~68.9K, in-domain ~23.5K, OOD ~7.6K (5,716 real + 1,920 fake from 20 held-out generators: CogVideoX1.5, HunyuanVideo, LTX-Video, SkyReels, Wan, Hailuo, Kling, Pika 2.2, PixVerse, Sora 2, Seedance 2.0...). Generator-disjoint split — evaluating generalization to unseen synthesis methods.
- Label generation: 5 MLLM annotators (GPT-4o, Gemini 3.5-Flash closed-source; Qwen2.5-VL open-source; Skyra, VideoVeritas forensics-tuned) independently generate observations + verdicts; DeepSeek-V4 Pro aggregator (pure text LLM — label aggregation operates over text reports + ground-truth metadata, no multimodal input needed; decoupled from the annotator pool → architectural independence, no inherited inductive biases). Observation labels: merge observations separately per dimension, guided by the ground-truth label to resolve cross-model contradictions and filter noise, WITHOUT revealing the verdict. Explanation labels: when correct predictions exist → prioritize synthesizing explanations from correct annotators; if all wrong → reverse inference — re-evaluate merged observations against the ground-truth label.
- Framework: uniformly sample frames X(v) → 4 observation agents, each receives the same frames + a dimension-specific prompt → textual observation WITHOUT predicting the verdict (texture agent: skin details, blending boundaries; lighting: illumination, shadow consistency; motion: temporal instability, flicker; physics: anatomical/geometric plausibility). Judge agent receives the 4 textual observations + optionally the video frames → weighs supporting/conflicting evidence → binary real/fake + concise verdict-consistent explanation.
- Training: 2 stages. (1) SFT: observation agents trained independently on dimension-specific observation labels (autoregressive LM loss); judge trained on concatenated observations + visual input. (2) GRPO (Group Relative Policy Optimization): judge only, observation agents frozen; G=8 candidate responses per prompt, binary accuracy reward r∈{0,1}, advantage A = (r − r̄)/(σ_r + ε) group-normalized, clipped surrogate objective + KL-divergence penalty against the frozen SFT policy (preserving explanation quality).
- Implementation: Qwen2.5-VL-7B base for all agents (fair comparison with Skyra); ms-swift; LoRA + AdamW; LR 1×10⁻⁴ (SFT), 5×10⁻⁶ (GRPO); 1 epoch; thinking mode disabled at inference.

## Key Findings
- OOD test set (Table 2): Ours (w/ Video) Acc 69.87%, Recall 81.82%, F1 53.28% — best across all metrics; Ours (w/o Video) 67.41/65.00/51.01 — second best. Strongest single-model baseline Gemini-2.5-Pro F1 47.45% → the framework improves F1 by +5.83pp absolute. Judge access to video directly: F1 51.01→53.28 (original visual information supplements expert reports).
- Comparisons: small vision models (DFGaze 56.67/17.92/27.24; DFD-FCG 61.25/29.22/39.16; Effort 63.92/34.79/44.76; TALL++ 63.47/42.97/45.07; TFCU 64.28/33.44/45.20); open-source MLLMs (Qwen2.5-VL-7B 35.94/16.51/13.24; InternVL3.5-8B 37.87/17.60/14.53; MiMo-V2.5 49.85/15.00/18.69; Qwen3.6-35B-A3B 53.17/50.05/35.72); closed-source (GPT-4o 57.63/40.36/37.55; GPT-5-mini 59.31/38.70/39.00; Gemini-2.5-Pro 63.78/75.29/47.45; Gemini-3.5-Flash 63.34/58.75/46.22); forensics-tuned (Skyra 60.50/78.96/38.30; VideoVeritas 57.87/65.00/43.22).
- Per-agent ablation (Table 3, all-four w/o Video 63.61/82.24/47.53): texture-only is the best single agent (58.39/97.40/44.53 w/o; 66.90/87.86/50.39 w/) — texture cues are the strongest; lighting is the weakest single (54.70/75.31/40.54). The single-agent vs all-four gap is clearer WITHOUT video → the 4 perspectives provide distinct evidence; with video, the judge recovers part of the missing visual information → gap narrows.
- Training stages (Table 4): Training-Free 45.06/65.05/33.53 (w/o Video); +SFT Only-Obs 50.63/99.58/40.46 (recall near 100% but low precision); +SFT Only-Judge 51.42/99.95/40.87; +SFT Joint 63.61/82.24/47.53; +SFT+GRPO 67.41/65.00/51.01 (w/o Video) — jointly training both components beats either alone; GRPO adds further gain.
- Reasoning strategies (Table 5, training-free): multi-turn variants (CoT, Multi-turn, Multi-turn-Obs, Multi-turn-All) do NOT improve over Single on Qwen2.5-VL-7B (F1 13.24 → 9.50–11.92, worse!) → the improvement comes from independent evidence collection + judge reconciliation, NOT from longer prompts, additional dialogue turns, or repeated frame access. InternVL3.5-8B: multi-turn helps (F1 14.53→25.85) but the framework still wins (29.81/30.52).

## Actionable Insights
1. Decomposing forensic analysis into 4 independent perspectives (texture/lighting/motion/physics) + judge reconciliation beats single holistic judgment: F1 47.45% (best single) → 53.28% (+5.83pp) on OOD generators unseen in training. Apply: when verifying content authenticity (marketing videos, UGC — user-generated content), run 4 agents checking the 4 aspects separately then a summary judge — cheaper (small open-source models) and more accurate than a closed-source GPT/Gemini single model.
2. Texture cues are the strongest signal (texture-only F1 44.53, recall 97.40%): skin over-smoothing, blending boundaries, plastic-like finger textures. Apply: when reviewing a suspect video, zoom into skin/edges/hands first — texture anomalies are where even the newest deepfakes still leak.
3. Multi-turn prompting does NOT help (even harms on Qwen2.5-VL-7B: CoT F1 11.29 < Single 13.24) — the improvement comes from specialization + reconciliation, not from longer reasoning chains. Apply: don't waste tokens on CoT/multi-turn with a single MLLM for deepfake detection; instead split the task across specialized agents.

## Assumptions & Limitations
- Conditions: the framework needs face-centric videos (the face detection pipeline filters frames without faces); the OOD split contains only EFS (entire-face synthesis) generators — FS/FR generalization on held-out methods is untested; all agents share the Qwen2.5-VL-7B backbone.
- Stated limitations (implicit): recall-precision tradeoff — Only-Obs recall 99.58% but F1 40.46 (very low precision); GRPO refines the decision policy but keeps observation agents frozen (observation quality capped by SFT).
- Unstated: dataset labels are produced by MLLM annotators + aggregator (not human-verified — potential annotator bias/hallucination in supervision); ground-truth-guided conflict resolution may be circular (annotators see the video, the aggregator knows the label → labels may leak label-specific artifacts); OOD recall 81.82% means 18% of fake videos are missed; precision is not directly reported (Acc 69.87% with 5,716 real + 1,920 fake → many reals misclassified); efficiency/latency of the 5-agent pipeline is not benchmarked (4 agents + judge sequential ≈ 5× inference cost); disabling thinking mode may underestimate MLLM baselines.
- Ethics: dual-use risk (deepfake detectors can be used in reverse to improve generators); the dataset contains crawled internet videos.
