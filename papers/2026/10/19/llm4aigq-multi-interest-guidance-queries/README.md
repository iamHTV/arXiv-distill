# 2609.03674v1 LLM4AIGQ: LLM-based AI Guidance Query Generation Framework for Multi Interest Mining

## Problem
- Guidance queries (các truy vấn gợi ý mua sắm) kích thích tiêu dùng bằng cách extract preferences (trích xuất sở thích) → search queries có guidance value (giá trị hướng dẫn), vai trò quan trọng trong e-commerce (thương mại điện tử).
- Traditional AIGQ (AI-generated queries — truy vấn do AI tạo) generation dựa trên two-stage "Query-to-AIGQ" (Q2AIGQ) association paradigm (mô hình liên kết hai giai đoạn): (1) recall user primary search queries (truy vấn tìm kiếm chính) từ user profiles, historical behavior sequences (chuỗi hành vi lịch sử), item-side information, current query qua multi-path retrieval (truy xuất đa đường); (2) generalize AIGQ qua rule-based methods (phương pháp dựa trên luật).
- Hai vấn đề: (a) semantic drift (trôi semantic) do information cascade loss (mất thông tin tầng) — intermediate-query bottleneck (nút cổ chai truy vấn trung gian); (b) anchor-query inference (suy luận truy vấn neo) bị chi phối bởi user-item co-occurrence relationships (quan hệ đồng xuất hiện) — thiếu exploration of user multi-interests (khai phá đa sở thích) → guidance queries low value, mismatched purchase intent (ý định mua hàng không khớp).
- Ba challenges: (1) multi-interest modeling under noisy interactions (mô hình hóa đa sở thích dưới nhiễu — accidental interactions, exposure bias); (2) effective supervision without explicit ground truth (giám sát hiệu quả khi không có ground truth — AIGQ không có câu trả lời đúng tuyệt đối); (3) efficient inference for online serving (suy luận hiệu quả cho serving online — latency constraints).

## Contribution
- LLM4AIGQ: LLM-based solution cho AIGQ tailored to users' multi-interests — segments user interests bằng cách integrate user profiles + historical interaction sequences, infers specific consumption intents (ý định tiêu dùng cụ thể) cho mỗi sub-interest (tiểu sở thích), generates corresponding AIGQ — tránh semantic drift, capture personalized intent.
- Three-stage post-training pipeline SFT → RL → DPO: SFT học style AIGQ (trên single-interest subsequences); RL với multi-level reward design (multi-objective optimization + long-chain reasoning); DPO distill reasoning capability từ think mode sang non-think mode (giảm token, tăng tốc inference).
- Deployment: nearline-generation and online-read architecture (sinh nearline + đọc online) — guidance queries được sinh trước, retrieval nhẹ online → đáp ứng latency constraints. Deployed tại Tmall, scale hundreds of millions of users (hàng trăm triệu người dùng).

## Method
- Data composition: input = task instruction R + user context C_u = user profile P_u (summarized/extracted bởi Qwen model từ consumption patterns + basic personal info) + user historical sequence S_u (recent behaviors B_u = timestamp t, behavior type a ∈ {like, favorite, add-to-cart, purchase, search}, behavior content c = query terms với search / item titles với các hành vi khác).
- Context compression: truncate history to most recent 50 behaviors; format "<idx><time><type><content>" phân cách bằng "|"; time = interval relative to current time. Item short titles: original titles thiếu standardized naming, poor readability, redundancy (marketing keywords, flagship stores) → Qwen3-30B-A3B summarize short title từ item title id + CPV info ic (brand/style/attributes) + brand category info ib (treecate_full_cath, treecate_name), fine-tuned bằng DeepSeek-V4 Pro outputs làm standard answer.
- SFT stage (single interest): teacher model (DeepSeek-V4 Pro) phân đoạn user interests + sinh guidance query per sub-interest làm reference; LLM được cung cấp ONLY single-interest subsequences → học style/patterns thay vì phải chọn giữa nhiều interests (directly fine-tuning trên composite interests → autonomous extrapolation, unfriendly với low-frequency trigger words, candidate AIGQs focus vào single main interest). Instructions chỉ ra application scenarios (single item consultation, comparative decision-making, category selection), yêu cầu guidance value + content compliance + concise expression.
- RL stage (multi-interest): model tự phân đoạn interests + sinh AIGQ per sub-interest với step-by-step reasoning: Step 1 — summarize multiple interests, divide thành at most 3 interest subsequences dựa trên temporal proximity, semantic relevance, profile preferences, interest label I_k; Step 2 — infer current consumption intent M_k + predict next preferred item i_k; Step 3 — generate 3 guidance queries + confidence score c mỗi query; Answer JSON {"interest_tag": [query1, query2, query3], ...}.
- Hierarchical multi-level rewards (4 granularities):
  (1) Think-level: R_match qua Optimal Ordered Matching Algorithm (DP — dynamic programming, Alg 1): reference subsequences Ŝ_u (m) vs model S_u (n), score(Î_i, I_j) = 2·(|Ŝ_i ∩ S_j|)/(|Ŝ_i|+|S_j|) · log(|Ŝ_i|+|S_j|) — primary interests earlier (length penalty); R_action(a,b) = 2(|Ŝ_a∩S_b|)/(|Ŝ_a|+|S_b|); R_logic(a,b) = cosine similarity giữa interest labels qua mge-small semantic encoder; R_think_format: detect ["Step1","Step2","Step3"] + JSON completeness → 1/0.
  (2) Query-level (per query): R_length ≤15 Chinese characters → 1/0; R_value: judge model trained on manually annotated data, rating r_t ∈ {S, A, B} → 1/0.5/0 (S: targeting specific consumer groups/usage scenarios, reflecting decisions, helping users understand item parameter differences; A: flagship store channel words, advertising statements, vague content; B: not smooth, non-e-commerce, unmappable to real item, brand category mismatch, unsafe content).
  (3) Interest-level (per cluster): R_sem = weighted cosine similarity giữa candidate queries và reference query (weights = normalized confidence scores); R_style = Type-Token Ratio (TTR — tỷ lệ token duy nhất/tổng token); R_format: số candidate queries = T đúng → 1/0.
  (4) Global-level: R_content = 1 − mean pairwise cosine similarity giữa mean-pooled cluster representations → khuyến khích diversified interests, tránh homogeneous expressions across clusters.
- GRPO optimization: R_response = R_think + R_query + R_interest + R_global (weighted aggregation); group size G=8, r_i(θ) = π_θ(o_i|q)/π_old(o_i|q), advantage A_i = (R_i − mean({R}))/(std({R})+ε), clipped surrogate − β·DKL. Reward weights: ω_think_format 0.5, ω_match 2.0, ω_length 0.2, ω_value 0.8, ω_sem 0.5, ω_style 0.3, ω_format 0.2, ω_content 0.5.
- DPO stage: positive samples y_w = RL checkpoint think-mode responses' final answers (discard reasoning traces); negative y_l = non-thinking-mode responses (70% từ RL checkpoints, 30% từ base model); preference-pair filtering: remove top 30% most semantically similar positive-negative pairs (unfiltered pairs chứa nhiều semantically similar cases → optimization unstable, templated/homogeneous outputs = "ineffective learning"); J_DPO với β temperature coefficient.
- Deployment: nearline pipeline invoke model sau mỗi N accumulated user interactions (clicks/favorites), non-thinking mode output multiple interest labels + guidance queries → write vào mapping table (user_id → guidance queries); online pipeline dùng efficient vector retrieval để locate index + retrieve personalized candidates real-time.

## Key Findings
- Offline test set (1,000 samples, Taobao/Tmall logs June–July 2026) — Value metric (Table 1, S/A/B ratio = tỷ lệ queries đạt rating S/A/B): S ratio: Qwen3-30B-A3B backbone 0.6405; Qwen3.5-122B-A10B 0.8251; Qwen3-235B-A22B 0.7940; GPT-oss-120B 0.7177; DeepSeek-V4-Pro 0.8152; LLM4AIGQ-MULTISFT 0.8044; LLM4AIGQ-ONESFT 0.8119; MULTISFT+RL 0.8138; ONESFT+RL 0.8360; MULTISFT+RL+DPO 0.8555; ONESFT+RL+DPO 0.8616 (best). B ratio giảm 0.1043 (backbone) → 0.0274 (best variant). ONE (single-interest SFT) > MULTI (mixed-interest SFT) ở mọi stage: 0.8119>0.8044, 0.8360>0.8138, và ONESFT+RL+DPO 0.8616 > MULTISFT+RL+DPO 0.8555.
- Ablation GRPO multi-level rewards (Table 3, Recall@10 / NDCG@10): LLM4AIGQ-ONESFT+RL 0.1771/0.2101; w/o think-reward 0.1696/0.1959 (relevance giảm mạnh nhất — think-level reward giám sát interest disentanglement); w/o query-reward 0.1727/0.2075; w/o interest-reward 0.1713/0.1922; w/o global-reward 0.1744/0.2034. Removing ANY reward component → declines both relevance and value.
- DPO: ONESFT+RL+DPO Recall@10 0.2377 vs ONESFT+RL 0.1771 (+34.2% relative); w/o preference-pair filtering 0.2182 (filtering +8.9% relative); MULTISFT+RL+DPO 0.2364 vs w/o filter 0.2127.
- Context compression (Table 2, 100 samples stress test): short titles vs original titles — input tokens 2.35k vs 3.21k (−26.8%), output tokens 146 vs 153, TTFT (time to first token — thời gian đến token đầu) 110ms vs 114ms, RT (response time — thời gian phản hồi) 2.84s vs 3.18s (−10.7%). Model output style bắt chước item title → title ngắn hơn → output concise hơn.
- A/B pairwise evaluation (Table 4, LLM-as-Judge Gemini-3.5-Flash vs teacher DeepSeek-V4-Pro, same user context, criteria: consistency với consumption intent, preferences, shopping-guidance value, content rationality, linguistic quality): base model win rate 34.63%; +SFT 50.25%; +SFT+RL 57.53% (surpass teacher); +SFT+RL+DPO 54.95% (slight drop — DPO trade-off reasoning quality vs inference efficiency, most RL capability preserved, vẫn trên teacher).
- Online A/B test (Tmall, shopping guidance/search/item detail pages): introducing AIGQ consistently improves user click performance; initial 10% traffic: +4.46% uCTR (user click-through rate — tỷ lệ nhấp) vs baseline bucket; scaled to 40% traffic: +2.53% uCTR over 6 days online validation. Deployed online at scale of hundreds of millions of users.
- Baselines insight: larger SOTA models show worse relevance than the 30B backbone — larger models tend to generate more novel queries (prone to hallucination in e-commerce), smaller models rely on high-frequency contextual terms.

## Actionable Insights
1. Multi-interest segmentation trước khi sinh query beats single-interest generation: S ratio 0.8616 (ONESFT+RL+DPO) vs 0.6405 backbone (+22.1pp top-rated queries), B ratio (unsafe/unmapped) 0.1043→0.0274. Áp dụng: khi sinh gợi ý content/product cho customer, trước hết phân đoạn customer thành ≤3 interest clusters (theo temporal proximity + semantic relevance), sinh query riêng per cluster — không gộp tất cả history vào 1 prompt (gây focus vào 1 main interest, lose low-frequency interests).
2. Hierarchical reward design (think/query/interest/global) với judge model rating S/A/B cho queries: removing think-level reward gây giảm relevance mạnh nhất; removing query-level degrades value. Áp dụng: khi dùng LLM sinh content, chấm điểm mỗi output bằng judge model theo rubric 3 mức (S: cụ thể nhóm khách hàng/scenario + so sánh parameter; A: chung chung; B: không map được sản phẩm) — chỉ giữ S/A, reject B.
3. DPO distillation từ think mode sang non-think mode giữ 96% gain (win rate 57.53%→54.95%) mà giảm token/reasoning cost; preference-pair filtering (remove top 30% most similar pairs) +8.9% Recall@10. Áp dụng: khi cần LLM nhanh (real-time recommendations), distill reasoning vào non-reasoning mode bằng DPO + filter cặp preference trùng semantic — đừng dùng raw think-mode output cho production latency-sensitive.
4. Item short-title compression (−26.8% input tokens, −10.7% RT) và output style bắt chước input title → title ngắn hơn, output concise hơn. Áp dụng: khi feed product data vào LLM, preprocess thành short titles (lược bỏ marketing keywords/flagship store words) — rẻ hơn và output gọn hơn.

## Assumptions & Limitations
- Điều kiện: cần teacher model (DeepSeek-V4 Pro) cho short titles + interest segmentation + reference queries; behavior sequence truncate 50 (chỉ capture short-term interests — long-term interests chỉ qua profile summary); max 3 interest subsequences/3 queries per interest; query ≤15 Chinese characters.
- Limitation paper thừa nhận (implicit): DPO trade-off — win rate giảm 57.53%→54.95% (reasoning quality vs efficiency); no universal evaluation metrics cho AIGQ (dùng relevance Recall/NDCG + S/A/B value ratings); user interests complex/diverse → positive samples có thể discrepant với history (mitigated bằng confidence-weighted evaluation).
- Limitation paper KHÔNG nói: labels phụ thuộc teacher model (DeepSeek-V4 Pro) — teacher bias truyền vào SFT/RL supervision; judge model rating S/A/B trained on manually annotated data — annotation cost/quality không discussed; online A/B test chỉ đo uCTR (không đo conversion/revenue); evaluation trên Taobao/Tmall (Chinese e-commerce) — transfer sang market khác chưa test; RL chỉ 100 steps (early stage, có thể underfit); think-level matching dùng subsequence overlap + semantic similarity — interest labels không được verify bởi human.
- Deployment dependency: nearline pipeline cần mapping table infrastructure + vector retrieval; non-thinking mode output quality phụ thuộc DPO distillation.
