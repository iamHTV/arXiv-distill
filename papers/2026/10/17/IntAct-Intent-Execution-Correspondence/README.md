# 2610.04375 — Do Tool Calls Execute as Intended? Measuring and Repairing Intent-Execution Correspondence in LLM Agents

## Problem
- Tool call reach chương trình qua nhiều hops: harness serialization → host wrapper → shell parse → process interface → target parser. Bất kỳ hop nào cũng có thể đổi call mà KHÔNG báo (quote consumption: `console.log("test")` tới tay program thành `console.log(test)`; re-expansion: `%PATH%`, `!x`; truncation: MSYS2 Git Bash cắt quoted argument tại 8,186 UTF-16 code units và collapse backslash pairs, cmd.exe kết thúc command tại line break đầu tiên; arity change: operand bị drop/split).
- Benchmarks/failure analyses đọc call + result nhưng KHÔNG đọc hop received gì → failure do path bị quy cho LLM. Command-execution problems = 25.0% của 3,864 bug reports của 3 coding agents. Trajectory-based analyses (Who&When) đọc trajectory — trajectory không chứa what a hop received.

## Contribution
- Định nghĩa intent-execution correspondence (IEC): executed action khớp action mà emitted call denotes dưới tool contract. FD(a,Π) = first hop receiver parse được action khác intent. Silent divergence = tool result không chứa error flag lẫn parser/quoting error message.
- IEC protocol: (A) witnesses observe what each hop received KHÔNG execute call (BASH_ENV file cho Bash; PowerShell parse rules không execution cho appended launch; argv probe tại process interface; argv sentry ghi ancestor processes khi có LLM in loop); (B) first divergence do receiver's OWN parser quyết định (KHÔNG string equality — string comparison misclassify 15/35 unchanged pairs thành changed; so sánh operators/words/heredoc bodies với Bash, parse tree với PowerShell, argument vector với program; verdict cho 99.98% của 32,259 Bash calls); (C) repair replay — replay recorded run với CHỈ hop named được repair (reply cache replay không LLM).
- IntAct: deliver call qua channel mà named hop KHÔNG parse (rendering condition) — sourced file cho Bash wrapper, native argument rendering cho PowerShell 5.1 process interface (native(s) = Eq. 1: escape quotes, double backslash runs), -EncodedCommand Base64(UTF16) cho wrapper, switch off history expansion/completion trước khi type vào interactive Bash. Refuse call không rendering nào carry được (multi-line dưới cmd.exe) — refusal names the hop. Compose renderings (later hop first) khi launch đổi call ở 2 hops. KHÔNG đổi call itself — action, cwd, environment giữ nguyên.
- IEC-Bench: 67 pattern pairs (hazard vs control khác đúng 1 literal), 10 multi-line programs, 135 ToolHop chains (3–7 steps), 46 Terminal-Bench 2 tasks, dưới 6 execution paths, 4 LLMs (qwen3-coder-plus, Qwen2.5-Coder-32B, Qwen2.5-72B, Hermes-3-Llama-3.1-70B).

## Method
- Measurement: replay recorded calls qua witness của từng hop; compare received action vs sent action bằng receiver parser. Windows corpus: 47,828 shell calls, 261 sessions, 6 developers, 11 weeks (Claude Code + Codex qua Git Bash và PowerShell 5.1). Exposed calls: heredoc, backslash pair, hoặc ≥1,000 ký tự (Bash); native program với constant args chứa quote/backslash/whitespace/empty (PowerShell) → 11,982 exposed.
- Attribution loud failure: parse agent text với execution disabled — không parse = generation error; parse được nhưng witness thấy khác = path; error ở line beyond end of text = path (wrapper-appended text); parse được, intact, gọi interpreter khác = nested hop.
- Repair selection: hop named (FD + second hop nếu launch đổi 2 lần) chọn rendering; KHÔNG đo lại per call.

## Key Findings
- RQ1 real-world: 1,199/11,982 exposed calls đổi (10.0%). Claude Code Bash launch: 12.0% của 7,491 exposed đổi; 67.0% với call có backslash pair; 100% với call ≥8,000 ký tự. 663 merged-backslash calls chạy → 535 (80.7%) silent wrong action KHÔNG báo lỗi. 11 cut calls đều fail có error. IntAct reroute 227 changed calls; 65/199 sessions (32.7%) có exposed call bị đổi; 23/27 sessions với ≥100 Bash calls.
- 10 harnesses đều đổi call tại 3/5 hops, hop khác nhau giữa harness và platform. PowerShell paths: script intact, đổi tại process interface (196/297 mất double quote trong value, 127 nhận số args khác). Qwen Code cmd.exe: 30/31 multi-line commands chạy như empty program. Linux: 4 harnesses đổi 0/80 runs — command truyền làm argument cho shell luôn intact (1,779 calls 4 harnesses, 4,012 calls 9 developers, 161,214 held-out Codex calls).
- Linux handlings không LLM: bash -c argument 0 đổi; Terminus-2 interactive typing 4 silent/3 error; SWE-ReX split+rejoin 12/1; OpenHands escaping 29/5; dash làm /bin/sh 45/27. Terminus-2 typing: 1,113/1,118 Toolathlon programs có expandable ! bị đổi vs 2/12,030 không có.
- Leaderboard: 4,434 Terminus-2/KIRA trials, 245 keystroke batches có tab/!, 186 đổi (81 tab, 105 history expansion) trong 137/4,356 scored trials. 203,710 public trajectories: "event not found" 2,546 lần trong 1,532/113,674 trajectories của typing harnesses, KHÔNG BAO GIỜ trong 90,036 của non-typing.
- Parse errors: 426 Bash/Python parse errors → 306 path-caused (253 cut, 46 merged backslash, 7 open quotes), 84 generation, 36 nested. Cả 306 được báo cho agent như lỗi "trong text của chính nó". 231/306: shortest wrapper deliver as written, chỉ longer session wrapper đổi → changed-call rate là lower bound.
- MCP: 16/22 servers test, 6/16 và 4/6 đổi payload; fetch server đổi backslash trong URL thành slash; SQLite server mô tả nonexistent table khi tên cần quoting; file-system server viết `a:b` vào alternate data stream của `a` trên Windows. Mỗi change báo success; tool description không nhắc.
- RQ2 IEC-Bench: 4 LLMs gặp changed call trong 16/71/63/34 chains (one-argument launch) và 128–133/135 (appended launch). Appended: 737/1,165 calls của qwen3-coder-plus đổi, 662 tại value có space. First changed call = first tool call trong 483/524 affected chain runs; parser reject 492.
- Score: Qwen2.5-72B dẫn Hermes-3 29 chains với direct JSON, nhưng thua 2 chains trên one-argument launch; IntAct sửa lại → dẫn lại 5 chains. Passed task tốn 2.4× tokens trên original launch vs IntAct; 12.3× cho chains và 7.9× cho pairs trên appended launch; 4.0× trên Claude Code Bash. Production: 162/306 path-caused failures recover bằng retry (2–8 steps), 30 abandoned, 114 không retry; mỗi call thành công tốn 3.9× tokens clean request.
- Pattern pairs: hazard variant pass 4–11/67 trên appended launch vs 38–46/67 trên control. Mọi empty-argument hazard fail trên cả 2 PowerShell launches; mọi truncation hazard fail trên Claude Code Bash; 0/10 multi-line programs pass trên appended. False-confirmation rate 70.1% (665/949 failed runs báo completed).
- Instruction delivery: as command-line argument → 33/46 instructions bị cut tại line break đầu, 3 mất hết double quotes, 5 vượt cmd.exe limit; as file → 46/46 intact. Argument delivery: mọi run score 0; file delivery: Qwen Code 6/30 Windows vs 7/30 Linux.
- Fix task: 13/13 API LLMs pass `"test_app (v2) & more.py"` cho pytest đúng, nhưng appended launch đổi thành AmpersandNotAllowed error — 45/45 runs fail first command, 2–7 steps, median 1.8× tokens. Commit task: intended message trong 1/39 runs, 19 false confirmations.
- RQ3 attribution: IEC protocol κ 0.77 với human labels (102 failures, 56 path-caused); all-at-once judge quy 97/102 cho LLM; Who&When judges κ ≤ 0.04. IEC gọi 0 LLM, Bash witness 0.1s/call. Action-change agreement κ 1.00 trên 115 pairs; string comparison κ 0.65.
- Replay baselines: Causal Agent Replay rescue 12/67 shell-only lost pairs CÓ changed call vs 29/53 KHÔNG có → rescue không chứng minh path. QuoteBench fixed-reply replay phát hiện 37.2% path-caused losses (51/137), mọi loss tại wrapper, 0 tại process interface.
- RQ4 repair: 168 fault injections (7 faults × 5 hops × 24 payloads): 30 đổi what target receives, first divergence names đúng hop trong 30/30 và 0/138 còn lại. IntAct restore mọi call 4 hops đầu, refuse 13 tại target parser; requoting/encoding chỉ restore phân số. Repair replay: 137/173 lost pairs có changed call pass khi repair named hop (79.2%; 68.6% one-argument → 90.9% Claude Code Bash); 0/187 không changed call pass (Fisher p<.001). Appended launch: process interface alone 0/69, wrapper alone 31, cả hai 69/81.
- Agent in loop: IntAct raise pass@1 mọi LLM mọi launch. Pooled Qwen2.5: +20 pairs/−1 loss (one-argument), +81/−5 (appended); +30 chains vs −1, +46 vs −1 (McNemar p<.001); +13/−2 Claude Code Bash (p=.007). Reflexion gain 11.4–55.0% của IntAct gain tại 463–1,180 retries/cell. Evidence ablation (call as sent + as received + named hop trong tool result): KHÔNG significant (p≥.500) — evidence không giúp agent sửa path. Boundary-disclosed contract: Qwen2.5-Coder-32B chain lệnh bằng `&&` mà PS 5.1 reject → rơi 50 pairs còn 36, vẫn báo completion.

## Actionable Insights
- Audit harness hop-by-hop, không chỉ end-to-end: mỗi harness đổi call tại hop riêng (Claude Code ở host wrapper, PowerShell paths ở process interface, typing harnesses ở shell parse). Ví dụ: chạy 20 payloads (quotes, backslashes, line breaks, special chars) qua argv sentry với mỗi harness trước khi tin benchmark score.
- Benchmark phải report launch và giữ fixed: cùng LLM, score chênh 29 chains chỉ vì transport (Qwen2.5-72B: 29 ahead với direct JSON, 2 behind trên PS 5.1). Ví dụ: đánh giá coding agent luôn chạy cả control transport (Git Bash from file) và direct JSON để tách LLM quality khỏi launch loss.
- Khi agent retry call đúng mà vẫn fail → nghi path, không phải LLM: 80.7% merged-backslash changes silent (không error), agent nhận "success" cho wrong action. Ví dụ: log received text tại wrapper (BASH_ENV witness) cho mọi Bash call có backslash pair/heredoc/≥1,000 chars — nếu received ≠ sent, quy cho path trước khi blame model.
- Deliver multi-line/long commands qua file hoặc argument vector, không qua command line: cmd.exe cắt tại line break đầu (30/31 multi-line chạy như empty program), MSYS2 cắt quoted arg tại 8,186 UTF-16 units. Ví dụ: thay `powershell.exe -Command <text>` bằng script file + `-File`, hoặc `-EncodedCommand Base64(UTF16(text))`.

## Assumptions & Limitations
- Rendering domain giới hạn: multi-line text dưới cmd.exe chỉ có thể refuse; 2/36 unrecovered pairs dùng construct ngoài domain.
- 12/36 unrecovered pairs abandoned sau misleading feedback — agent-side issue IntAct không fix (evidence trong tool result không giúp, p≥.500).
- Changed-call rate là lower bound: 231/306 path-caused failures chỉ đổi ở longer session wrapper, shortest wrapper replay không thấy.
- Measurement trên Windows 11 + PowerShell 5.1 + Git for Windows và Linux shared host; macOS/zsh chỉ đo riêng (zsh silently đổi 5 reference solutions).
- IEC-Bench hazard classes viết lại với literals mới (không release session text) — generalization sang các literal khác chưa test trực tiếp.
- Repair replay cần recorded run (calls + tool results) — không áp dụng cho production live traffic không có recording.
