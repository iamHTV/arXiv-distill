# 2610.10827v2 Grammar Concept Annotation at Scale: Deployed Fine-Tuned Small Language Models Outperform Prompted Frontier Models

## Problem
- Corrective feedback is among the best-evidenced drivers of second-language acquisition, yet corrections given during lessons rarely accumulate into an actionable view of grammar mastery. Prompted frontier models (GPT-5.4) can produce such a view from learner–tutor lesson transcripts, but they are costly at scale: the pilot's 3,810-token prompt per request (listing all 34 concepts, edge cases, and examples) exceeded the serving budget, causing prefill latency and dominating KV-cache memory in vLLM. This matches a broader enterprise AI pattern: many products stay in pilot and only ~5% reach production.

## Contribution
- An end-to-end grammar mastery tracking system deployed to ALL English learners on Preply: speech-to-text transcripts → extract learner utterances + upstream corrections → annotation model predicts in a single pass a set {(concept, exact span, correctness, explanation)}; aggregates into overall and per-concept mastery scores weighted by concept frequency, CEFR level, and a forgetting curve; every piece of evidence is traceable to a highlighted span in the learner's sentence.
- A formulation of learner grammar feedback as grammar concept annotation (34 concepts) with two human-curated benchmarks (Golden: 689 utterances mirroring production; Golden2: 2,977 utterances, error-enriched with 95.6% error-bearing) and nested criteria L1 concept / L2 +exact span / L3 +correctness.
- A data quality pipeline (evidence-grounded review, deterministic validation, filtering, synthetic enrichment) that adds 36.9–40.7 percentage points of strict L3 recall over raw teacher supervision.
- A production serving architecture: 0.8B SLM + prompt compaction (3,810 → 375 tokens, −90.2%) + native vLLM + autoscaling → ~16× serving cost reduction (cost per lesson is 6.2% of the GPT-5.4 baseline).

## Method
- Fine-tuning: Qwen3.5 base models (0.8B deployed, 4B reference), completion-only LoRA (rank r=128 on all linear layers for 0.8B, r=16 for 4B); packing five utterance–correction pairs per conversation; 90/10 split; over-length examples discarded rather than truncated; checkpoints selected by minimum teacher-forced validation loss, four evaluations per epoch, early-stopping patience of three.
- Three-stage data pipeline: (i) review of production annotations (50k uniform + 50k heuristic sampling prioritizing anomalies) using a hybrid neuro-symbolic approach — spaCy deterministic linguistic anchors + hand-crafted rules + word-level edit differences from the correction, a GPT-5.4 full review/re-annotation pass, and a deterministic post-validator enforcing contract invariants (reject non-substring spans, prune invalid labels, enforce explanation consistency); (ii) synthetic enrichment via structural backbones (concept-label + correctness-flag sequences) sampled in three 30k subsets (uniform, error-weighted, smoothed inverse concept-frequency), pedagogical errors injected into the generation plan (within-concept misuse, omission, confusable structure substitution), realized by GPT-5.4, then post-validated; (iii) consolidation: deduplication (1.4% overlap) and removal of any utterance present in the golden benchmarks → ~187k utterance groups (100k reviewed production + 90k synthetic, pre-dedup).
- Serving: vLLM on autoscaled single-GPU g6.2xlarge SageMaker instances; packed five-pair requests; validation or service failures route to a GPT-5.4 fallback.
- Evaluation: micro precision/recall at L1/L2/L3; 20,000 paired nonparametric cluster bootstrap confidence intervals; two-sided paired randomization tests with 20,000 permutations; explanations judged by GPT-5.5 (LLM-as-a-judge) with human audit and reconciliation.

## Key Findings
- Golden: fine-tuned 4B L3 precision/recall 81.28/83.49, fine-tuned 0.8B 80.84/78.89 — both beat prompted GPT-5.4 (67.81/62.87) and GPT-5.6 Sol (67.04/58.66); base models nearly fail to parse (4B base L3 3.01/16.56; 0.8B base 3.10/10.73; parse failures 26.9–32.8% and 75.3–92.0%).
- Golden2 (error-enriched): 4B fine-tuned L3 82.74/85.16, 0.8B fine-tuned 82.55/80.88 vs GPT-5.4 74.37/76.04 and GPT-5.6 Sol 74.97/72.39 — fine-tuned SLMs win at every matching level in both precision and recall; all fine-tuned Qwen–GPT-5.4 differences significant at p < 0.0001.
- Pipeline ablation: full pipeline vs raw supervision at matched size — Golden2 L3 precision +28.37 (4B) / +29.93 (0.8B) pp, L3 recall +36.91 [35.93, 37.87] / +39.95 [39.01, 40.89] pp; Golden L3 recall +37.33 / +40.66 pp; Rare-9 recall up +45.31/+45.81 pp (Golden2); raw supervision degrades L1→L2 by 23.64–23.78 pp vs 6.28–6.31 pp for the full pipeline (exact-span robustness).
- Explanation quality: the uncalibrated GPT-5.5 judge rated GPT-5.4 explanations 99.06% acceptable vs 94.91% (4B) and 93.88% (0.8B); after human audit and reconciliation all three reached ≈95% with no significant difference — the uncalibrated judge favored its frontier sibling.
- Online A/B, 35 days, learner-level randomization, 50% exposure: engagement with progress +15.80% (p<0.001), scheduled hours (CUPED) +2.06% (p=0.021), confirmed hours from new tutoring +10.87% (p=0.039), GMV from new lessons +13.20% (p=0.020) — all 95% CIs exclude zero; the gains belong to the end-to-end feature, not the SLM in isolation.
- Serving: 8 g6.2xlarge instances sustained throughput above the post-rollout peak; a 31-day APM snapshot showed p95 latency 4.3 s; recurring detection cost per lesson is 6.2% of the GPT-5.4 baseline (≈16× reduction).

## Actionable Insights
- Prompt internalization: fine-tune a small model on teacher demonstrations to compress a verbose system prompt into adapter weights — the prompt shrank 3,810 → 375 tokens (−90.2%), max sequence 7,000 → 2,500, cost ~16× lower while quality went UP (Golden L3 recall 62.87 → 78.89). Example: any production feature with a multi-thousand-token system prompt is a fine-tuning candidate.
- Budget for data quality, not volume: review + deterministic validation + synthetic rebalancing added 36.9–40.7 pp of strict recall; raw teacher supervision degrades sharply on exact-span matching. Example: when fine-tuning on LLM-generated labels, spend most effort on the review pass and post-validator, not on generating more data.
- Calibrate LLM judges with human audit before trusting comparative evaluations: the uncalibrated judge showed a 5.2 pp gap favoring itself (99.06% vs 93.88%), and human audit reconciled to ≈95% parity. Example: any "model A beats model B" result from an LLM-as-a-judge needs a sampled audit.

## Assumptions & Limitations
- Conditions: the annotation model receives the utterance + upstream correction (not the full transcript); GPT-5.4 fallback on validation/service failure; a 34-concept curriculum (the next iteration has 300+ fine-grained concepts).
- Limitations acknowledged: the pipeline ablation does not isolate individual components; a single training run per configuration with no across-seed variance — fine-grained metric differences should not be over-interpreted; the 4B and 0.8B use independently tuned recipes and prompt lengths, so size differences are not an isolated parameter ablation (the 0.6B is an earlier Qwen generation); the A/B test evaluates the end-to-end feature; the cost model excludes upstream transcription, correction, and fallback calls; explanations were evaluated against gold rubrics, not perceptual studies with teachers or learners; ASR noise cascade is not isolated; systematic teacher (GPT-5.4) biases may persist.
- Not stated: the Golden/Golden2 benchmarks are not public (privacy) so results are not directly replicable; the 8-instance load test may not cover tail traffic; the GPT-5.4 fallback cost is not counted in the 16× reduction; packed five-pair batching assumes transcripts have enough utterances.
