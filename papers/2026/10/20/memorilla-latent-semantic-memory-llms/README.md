# [2610.21375v1] MEMORILLA: Latent Semantic Memory for LLMs

## Problem
- Deployed LLMs cần memory (accumulated knowledge: user preferences, long documents, KB facts) nhưng 2 existing paradigm đều có vấn đề: (a) retrieval-based (RAG, Mem0, MemoRAG) — user preferences rarely share wording với query → similarity-based retrieval không tìm/combine được relevant info (personalization yếu); multi-hop relational reasoning degrade khi chain spans nhiều docs (RAG-50 trên FactKG drop 78.73→51.75 khi composed facts 1→4); (b) full-context — prompt grows proportional với corpus → cost/latency explode (19.9s vs 0.74s end-to-end) VÀ "full context is not an upper bound" — nó HURTS more often than helps. Prior work (xRAG, ComMer) compress context thành latent embeddings nhưng chưa có system persistent, query-conditioned memory w/ strong results across personalization + long-doc + knowledge QA + agent continual learning.

## Contribution
- MEMORILLA: latent semantic memory system (hệ thống memory ngữ nghĩa tiềm ẩn) cho frozen LLMs. Tách persistent knowledge storage khỏi per-query context: frozen document encoder embed corpus ONCE → query-independent store ZD (tính 1 lần, persist); trainable memory module f_mem đọc store theo query → K query-conditioned soft memory tokens (memory token mềm) projected into frozen LLM embedding space, prepended trước query text. LLM xử lý memory + text trong cùng input sequence — KHÔNG change any LLM layer/attention. Documents thêm mới KHÔNG cần update LLM.
- First combined system: supervised memory (answer NLL loss) + RL continual learning (GRPO trên environment reward, chỉ train memory module) cho agent tasks.

## Method (tóm tắt cốt lõi)
- Encoding: frozen Qwen3-Embedding-4B → ZD ∈ R^{N×he} (1 lần); query encoder frozen → zq. 4-stage memory module (194,123,776 trainable params, K=16 typically): (1) slot init — learned Q0 shared across collections/queries; (2) query conditioning Qc = LayerNorm(Q0 + CrossAttn(Q=Q0, K=zq, V=zq)); (3) document retrieval — L_ref Perceiver-style cross-attention blocks attend ALL N stored embeddings (continuous query-conditioned read, NOT discrete top-k); (4) projection Wproj he→hL → M = [m1..mK].
- Injection: X_LLM = [m1..mK ; Pq]; standard RoPE over combined sequence; frozen LLM (Qwen3-8B default) attends memory qua existing self-attention. Loss = NLL on answer positions only (không prompt/memory positions).
- Training 3-stage curriculum: Stage 1 — 1.98M English Wikipedia paraphrase reconstruction; Stage 2 — 1.34M examples từ 10 datasets (reading comprehension, open-domain QA, summarization); Stage 3 — unified mixture train splits of all 8 eval benchmarks (multi-task checkpoint cho 6; PMv2/PV4 benchmark-specific fine-tune).
- Baselines: RAG-50 (top-50 cosine), Mem0, MemoRAG (cả hai thêm Qwen3-4B-Instruct-2507 build memory), xRAG, ComMer (reported results), LLMLingua-2 (task-agnostic prompt compression) — cùng frozen Qwen3-Embedding-4B + Qwen3-8B decoder. Context budget 32,768-token decoder, YaRN khi full-context vượt.
- TextWorld continual learning: frozen Qwen3-4B-Instruct-2507 agent + memory K=8; mỗi turn thêm doc mới; memory module random init + GRPO (sparse reward, G=16 rollouts); same input budget 16,000 tokens training / 4,096 evaluation as ICL baseline → improvement reflects memory content, không phải info access.

## Key Findings
- 8 benchmarks (PMv2, LaMP-4, LaMP-7, PersonalizationV4, NarrativeQA, TriviaQA, FactKG, PubMedQA): MEMORILLA outperforms ALL baselines on average (49.68 vs xRAG 41.92, LLMLingua-2 40.75, Mem0 38.02); Pareto frontier MỌI benchmark, leads 5, second 2 (NQA, PV4); 394×/113×/49× fewer document tokens than full context/RAG-50/MemoRAG (geometric mean); range 20×–4,212×; >4,000× context compression.
- FactKG (claim verification vs KB): 84.33% vs full-context 80.43%, MemoRAG 80.38%, xRAG 78.98%; 108× fewer tokens than full context, 36× vs MemoRAG; advantage grows monotonically with entity count +4.23pp (1 entity) → +7.59pp (4+); MEMORILLA stable 80–89 range across composition depths khi RAG-50 drop 78.73→51.75 (facts 1→4); 73.5% FactKG claims có >50 chunks.
- TriviaQA EM 57.00 (MemoRAG 56.60, full-context 52.60) với 743× fewer tokens than full context, 19× vs MemoRAG. PMv2 short-answer 44.60% vs xRAG 30.90% strongest baseline — all other baselines (incl full context) within ~3 points of closed-book 25.64%, dùng 1,974× more tokens than MEMORILLA. LaMP-7 ROUGE-L 43.13→48.37 (closed-book ~43); tất cả baselines trừ xRAG (46.84) trong 1 điểm closed-book. LaMP-4 18.15 ROUGE-L vs full-context 14.21, 474× fewer tokens.
- Latency end-to-end 0.74s (MEMORILLA) vs 19.9s full-context answer generation.
- Where memory does NOT help: MemoRAG leads NarrativeQA ROUGE-1/L 21.80/20.51 vs 19.68/19.31 + PV4 67.88% vs 66.65% (cần 50×/690× more tokens — verbatim access); PubMedQA (4 abstracts, 324 tokens total): LLMLingua-2 69.00%, four baselines 67.00%, MEMORILLA 59.00% — small collections không benefit.
- Full context trails MEMORILLA mọi benchmark trừ PubMedQA + 20/21 metrics; RAG-50 exceeds full context trên 15.
- Analysis: NQA question types — MEMORILLA +4.91 ROUGE-L "why", +7.02 "how" (conceptual/causal reasoning); RAG-50 +3.45 "who", +2.93 "which" (verbatim entity recall) → compression preserves global structure, loses exact surface tokens. Complementarity FactKG: 15.9% MEMORILLA-only vs 10.0% RAG-50-only; PMv2 27.1% vs 9.2%; union oracle exceeds either mọi benchmark → hybrid memory+retrieval future work. Both-wrong: PV4 errors cần linking facts (combining failure not finding failure); FactKG both-methods bias false claims — true claims 89.5% joint-wrong vs 28.7% joint-right → miscalibrated threshold, KHÔNG missing evidence.
- Personalization case (PMv2): MEMORILLA personalizes generic query via remembered iron-deficiency anemia history dù KHÔNG lexical overlap query↔history.
- TextWorld: avg@3 0.186→0.242, pass@3 0.250→0.375 vs full-history ICL; untrained memory WORSE than ICL (0.153/0.225) → gain from learning; agent completes 37.5% held-out games ≥1/3 attempts vs 25.0%; ICL exhausts 4,096-token budget 71% rollouts vs 58% MEMORILLA; trained memory escapes navigation loops + executes keyed action sequences (unlock→open container); failures concentrate longest games (≥50-turn backtracking).

## Actionable Insights
- Thay full-context feeding bằng trained latent memory module cho LLM assistant có accumulated history: token giảm 394× (geometric mean), latency 0.74s vs 19.9s, quality TĂNG không giảm (49.68 vs baselines ≤41.92; FactKG 84.33 vs full-context 80.43). Ví dụ: customer-support assistant với 5,000 past conversations — embed once, 16 soft tokens per query, personalization answers without re-sending history mỗi query.
- Memory beats retrieval KHI query wording ≠ stored wording (preference recall, cross-doc relations): PMv2 44.6 vs 30.9; fact-check multi-entity stays 80–89 range khi RAG drop xuống 51.75. Ví dụ: recommend products cho returning user — memory captures preferences semantically, RAG miss vì user không lặp lại wording cũ.
- Dùng hybrid memory + RAG cho exact entity recall: MEMORILLA wins conceptual ("why/how" +4.91/+7.02), RAG wins verbatim ("who/which" +3.45/+2.93), union oracle > either mọi benchmark. Ví dụ: knowledge assistant — memory tokens cho reasoning + retrieval tokens cho names/IDs/numbers, combine trước khi generate.

## Assumptions & Limitations
- Điều kiện: corpus build được embeddings (frozen encoder); memory module phải train (3-stage curriculum ~3.3M examples, 194M params) — KHÔNG drop-in; encoder+decoder pairing tested Qwen3 only; K fixed memory budget.
- Paper thừa nhận: loses fine-grained factual details (encoder never trained for memory compression); cross-model-family transfer untested (Qwen encoder+decoder pairing); may not carry to coding domains; LLM decoding dominates latency → efficiency gains mainly for LARGE collections; privacy: stored embeddings encode sensitive info (consent needed; but can delete on request / keep on device since memory external to LLM).
- Limitation paper KHÔNG nói: PersonalizationV4 fully synthetic (GPT-5 personas) — real-user generalization untested; TextWorld toy text-game environment, production agent tasks untested; eval hack PMv2/PV4 = cosine nearest neighbor among predefined answer choices (không free-form); training cost heavy (2 frozen models 4B+8B + 194M trainable + curriculum) vs pure RAG; compression lossy intrinsically — exact recall needs RAG hybrid; claim-verification threshold miscalibration cần post-hoc calibration; "20 to 4,212×" range includes best-case — per-benchmark actual savings vary (19×–1,974×); ComMer baseline only via reported results (không re-run).
