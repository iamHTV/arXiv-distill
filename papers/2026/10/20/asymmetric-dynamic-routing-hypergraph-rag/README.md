# [2609.29282v2] Asymmetric Dynamic Routing: Balancing Reasoning Depth and Computational Efficiency in Hypergraph RAG

## Problem
- Graph/hypergraph-based RAG (GraphRAG, LightRAG, Hyper-RAG, DHI) reduce hallucination nhưng existing structure-based RAG systems dùng STATIC traversal strategies (strategy traversal tĩnh): subgraph expansion radius + traversal depth uniform cho MỌI query dù complexity khác nhau. Authors define "static retrieval fallacy (bẫy retrieval tĩnh)": 2 contrasting problems — (a) computational redundancy cho simple queries (simple query bị force deep traversal → thừa token), (b) cognitive context gaps cho complex reasoning tasks (complex query bị force shallow retrieval → thiếu ngữ cảnh). Prior work chưa adapt retrieval depth + traversal direction theo query complexity.

## Contribution
- ADR (Asymmetric Dynamic Routing — định tuyến động bất đối xứng): intent-conditioned retrieval framework (khung retrieval điều kiện theo intent) operating over hierarchical knowledge graphs (KG phân cấp). Lightweight structured classifier (bộ phân loại cấu trúc nhẹ) dynamically dispatch queries among 3 asymmetric topological traversal operators (toán tử traversal topo bất đối xứng): localized fact anchoring (neo fact cục bộ), bottom-up adjacency diffusion (khuếch tán adjacency bottom-up), top-down insight grounding (ground insight top-down) — collectively enable bidirectional information flow (luồng thông tin 2 chiều) across hierarchical knowledge layers (tầng knowledge phân cấp).

## Method (tóm tắt cốt lõi)
- Dual-hypergraph representation (biểu diễn siêu đồ thị kép) G=(HK, HD) theo DHI framework: HK=(VK, EK) factual hypergraph (siêu đồ thị fact) — VK factual entities, EK pairwise factual relations (|e|=2) + higher-order factual hyperedges (|e|≥3, quan hệ liên hợp nhiều entities); mỗi higher-order hyperedge gắn atomic direct insight ι(e) và mapped π → insight vertex trong VD. HD=(VD, ED) deep insight hypergraph — insight edges ε ∈ ED nối set insight vertices, mang synthesized narrative insight I(ε).
- Intent routing: classifier phân loại query q → Y={1 simple, 2 moderate, 3 complex} với confidence; conservative fallback (fallback thận trọng): confidence < γ (default 0.75) → Moderate trajectory. Λ quá thấp (0.50) misroute ambiguous queries (Logicality −1.14 on CS); γ≥0.85 → 68.4% queries fallback Moderate, +58ms latency, no significant gain (p>0.05).
- Operator 1 (Simple): localized fact anchoring — entity anchor set Vas = top-k_e factual entities by cos(e_v, q); Esub = {e ∈ EK | e ∩ Vas ≠ ∅}; retrieve Esub, terminate (zero-hop-like, no neighborhood expansion/cross-layer).
- Operator 2 (Moderate): bottom-up adjacency diffusion — Useed = {π(e) | e ∈ Esub, |e|≥3}; Eup = {ε ∈ ED | ε ∩ Useed ≠ ∅} single adjacency expansion in HD; joint factual content (Esub) + narrative insights (Eup).
- Operator 3 (Complex): top-down insight grounding — E* = top-k_d deep insight edges by cos(e_ε, q); Eground = {π−1(u) | u ∈ ε ∈ E*} ⊆ EK inverse cross-layer mapping (ánh xạ cross-layer ngược); joint narrative insights (E*) + granular facts (Eground).
- Config: GPT-4o-mini backbone, text-embedding-3-small, temperature T=0 deterministic; evaluation normalized LLM-as-a-Judge 0–100 trên 5 dimensions: Comprehensiveness, Diversity, Empowerment, Logicality, Readability.

## Key Findings
- Datasets 5 domains: Mix, CS, Agriculture (UltraDomain — sparse: Mix cross-domain sparse; CS/Agri intra-domain sparse, weak inter-passage dependencies) + Neurology, Pathology (MIRAGE — intra-domain dense, strong semantic continuity).
- Overall scores (0–100) ADR beats ALL 6 baselines trên mọi dataset: Mix 83.91 (DHI 83.18, GraphRAG 81.06, NaiveRAG 78.09, LLM zero-shot 79.30); CS 85.24 (DHI 84.66, GraphRAG 84.03); Agri 83.86 (DHI 82.97, Hyper-RAG 81.98); Neuro 85.02 (DHI 84.23); Pathology 86.65 (DHI 85.78, LightRAG 84.43).
- Routing ablation (Table 3): ADR dynamic beats BEST fixed configuration +1.39 (Mix), +2.11 (CS), +1.16 (Agri), +0.94 (Neuro), +1.25 (Patho). Modality varies: CS Complex-only 83.13 > Moderate-only 82.14 (sparse setting benefits deeper retrieval); Moderate-only beats Complex-only 1.39 (Agri: 82.70 vs 81.31) + 1.51 (Patho: 85.40 vs 83.89) — additional traversal depth does NOT always improve quality. NO fixed mode consistently optimal across knowledge settings.
- Efficiency (Table 4, vs Complex-only): average latency 435ms → 238ms (−45.3%); prompt tokens 3,760 → 1,929 (−48.7%); overall score 82.05 → 83.91 (+1.86) — giảm cost VÀ cải thiện quality đồng thời.
- Qualitative (Pathology causal query "how somatic IDH1 mutations promote gliomagenesis through epigenetic remodeling"): classified Complex cy=0.94; Simple-only misses causal chain (chỉ localized IDH1/R132H facts); Complex-only retrieves 3,850 tokens tangential biochemical context (kể cả EGFR amplification irrelevant); ADR: top-down identifies causal mechanism — mutant IDH1 drives 2-hydroxyglutarate (2-HG) accumulation → inhibits α-KG-dependent dioxygenases → induces epigenetic remodeling — then π−1 grounds in IDH1 R132H mutation facts; 41.2% fewer prompt tokens than Complex-only, causally coherent, fewer hallucinated associations.

## Actionable Insights
- Đừng dùng retrieval tĩnh cho mọi query: install query-complexity classifier + 3 routing modes trong RAG pipeline — latency −45.3% (435→238ms), prompt tokens −48.7% (3,760→1,929), quality +1.86 điểm. Ví dụ: knowledge-base assistant — query "refund window bao lâu?" chỉ cần anchor facts (zero-hop-like), query "tại sao churn tăng sau change giá?" cần top-down insight grounding; routing đúng cắt ~một nửa token mà không mất chất lượng.
- Routing depth phải khớp knowledge setting: sparse corpus (docs ít liên kết) có thể benefit từ deeper traversal (CS Complex-only +1.09 over Moderate), nhưng dense corpus Moderate-only thắng Complex-only (+1.39–1.51) — depth thừa hại quality. Ví dụ: đo per-domain best mode trước khi freeze config; dùng dynamic routing thay vì 1 mode toàn cục.
- Complex queries cần insight-level navigation, không chỉ fact retrieval: top-down insight edges + π−1 grounding cho causal chain + verifiable facts; Complex-only naive retrieval 3,850 tokens tangential (EGFR irrelevant). Ví dụ: research assistant — retrieve insight narratives trước rồi anchor về docs gốc, tránh context dilution.

## Assumptions & Limitations
- Điều kiện: corpus phải build được dual-hypergraph (entities + higher-order factual hyperedges + insight mapping π); backbone generation + embedding model fixed (GPT-4o-mini + text-embedding-3-small); γ threshold calibration được trên query distribution.
- Paper thừa nhận: Intent Routing operates independently of real-time graph structure — Complex query trong structurally sparse domain: insufficient graph connectivity giới hạn supporting facts từ Top-Down Insight Grounding → cần fallback dense vector search; constructing dual-hypergraph incurs upfront indexing costs (trade-off offline construction vs online inference efficiency).
- Limitation paper KHÔNG nói: evaluation chỉ LLM-as-a-Judge normalized scores (0–100) — KHÔNG exact-match/F1 factual correctness, KHÔNG human evaluation → "quality" là judge perception không phải ground truth; routing classifier details thin (construction/accuracy không report — chỉ γ sensitivity); 3 discrete categories + conservative fallback — continuous soft routing là future work; single backbone + T=0 — backbone generalization untested; Table 1 dataset statistics bị extract lộn (per-cell attribution unreliable — corpus sizes unverifiable); ablation χưa tách contribution classifier vs operators; fallback→dense-vector path chưa được evaluated định lượng.
