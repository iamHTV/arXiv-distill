# [2609.29282v2] Asymmetric Dynamic Routing: Balancing Reasoning Depth and Computational Efficiency in Hypergraph RAG

## Problem
- Graph/hypergraph-based RAG (GraphRAG, LightRAG, Hyper-RAG, DHI) reduces hallucinations, but existing structure-based RAG systems use STATIC traversal strategies: uniform subgraph expansion radius and traversal depth for EVERY query regardless of complexity. The authors define the "static retrieval fallacy": two contrasting problems — (a) computational redundancy on simple queries (forced deep traversal wastes tokens), (b) cognitive context gaps on complex reasoning tasks (forced shallow retrieval lacks context). Prior work did not adapt retrieval depth + traversal direction to query complexity.

## Contribution
- ADR (Asymmetric Dynamic Routing): an intent-conditioned retrieval framework over hierarchical knowledge graphs. A lightweight structured classifier dynamically dispatches queries among three asymmetric topological traversal operators — localized fact anchoring, bottom-up adjacency diffusion, top-down insight grounding — enabling bidirectional information flow across hierarchical knowledge layers.

## Method (core)
- Dual-hypergraph representation G=(HK, HD) following the DHI framework: HK=(VK, EK) factual hypergraph — VK factual entities, EK pairwise factual relations (|e|=2) + higher-order factual hyperedges (|e|>=3 capturing joint relations among multiple entities); each higher-order hyperedge carries an atomic direct insight iota(e) mapped by pi to an insight vertex in HD. HD=(VD, ED) deep insight hypergraph — insight edges epsilon connect sets of insight vertices and carry synthesized narrative insights I(epsilon).
- Intent routing: the classifier assigns each query to Y={1 Simple, 2 Moderate, 3 Complex} with confidence; conservative fallback when top confidence < gamma (default 0.75) -> Moderate trajectory. Too-low gamma (0.50) misroutes ambiguous queries (Logicality -1.14 on CS); gamma>=0.85 sends 68.4% of queries to the Moderate fallback (+58ms latency, no significant gain, p>0.05).
- Operator 1 (Simple, localized fact anchoring): entity anchor set Vas = top-k_e factual entities by cos(e_v, q); Esub = {e in EK | e intersect Vas != empty}; retrieval terminates at Esub (zero-hop-like — no neighborhood expansion, no cross-layer traversal).
- Operator 2 (Moderate, bottom-up adjacency diffusion): Useed = {pi(e) | e in Esub, |e|>=3}; Eup = {epsilon in ED | epsilon intersect Useed != empty} — a single adjacency expansion in HD; joint factual content (Esub) + narrative insights (Eup).
- Operator 3 (Complex, top-down insight grounding): E* = top-k_d deep insight edges by cos(e_epsilon, q); Eground = {pi^-1(u) | u in epsilon in E*} subset EK — inverse cross-layer mapping grounding insights in verifiable facts; joint narrative insights (E*) + granular facts (Eground).
- Configuration: GPT-4o-mini generation backbone, text-embedding-3-small, temperature T=0 (deterministic); normalized LLM-as-a-Judge scoring 0-100 on five dimensions: Comprehensiveness, Diversity, Empowerment, Logicality, Readability.

## Key Findings
- Five domain datasets: Mix, CS, Agriculture (UltraDomain — sparse: Mix cross-domain sparse, CS/Agri intra-domain sparse with weak inter-passage dependencies) and Neurology, Pathology (MIRAGE — intra-domain dense with strong semantic continuity).
- Overall scores (0-100): ADR beats all six baselines on every dataset — Mix 83.91 (DHI 83.18, GraphRAG 81.06, NaiveRAG 78.09, zero-shot LLM 79.30), CS 85.24 (DHI 84.66, GraphRAG 84.03), Agriculture 83.86 (DHI 82.97, Hyper-RAG 81.98), Neurology 85.02 (DHI 84.23), Pathology 86.65 (DHI 85.78, LightRAG 84.43).
- Routing ablation: ADR (dynamic) beats the BEST fixed configuration by +1.39 (Mix), +2.11 (CS), +1.16 (Agriculture), +0.94 (Neurology), +1.25 (Pathology). The best mode varies: on CS, Complex-only 83.13 > Moderate-only 82.14 (sparse settings benefit from deeper retrieval); Moderate-only beats Complex-only by 1.39 (Agriculture: 82.70 vs 81.31) and 1.51 (Pathology: 85.40 vs 83.89) — additional traversal depth does not always improve quality; NO fixed mode is consistently optimal across knowledge settings.
- Efficiency vs Complex-only: average latency 435ms -> 238ms (-45.3%); prompt tokens 3,760 -> 1,929 (-48.7%); overall score 82.05 -> 83.91 (+1.86) — cost reduction AND quality improvement simultaneously.
- Qualitative (Pathology causal query, "how somatic IDH1 mutations promote gliomagenesis through epigenetic remodeling"): classified Complex (confidence 0.94); Simple-only misses the causal chain (localized IDH1/R132H facts only); Complex-only retrieves 3,850 tokens of tangential biochemical context (including irrelevant EGFR amplification); ADR top-down identifies the mechanism — mutant IDH1 drives 2-hydroxyglutarate (2-HG) accumulation -> inhibits alpha-KG-dependent dioxygenases -> induces epigenetic remodeling — then pi^-1 grounds it in IDH1 R132H mutation facts: 41.2% fewer prompt tokens than Complex-only, causally coherent, fewer hallucinated associations.

## Actionable Insights
- Stop using static retrieval for every query: add a query-complexity classifier + three routing modes to your RAG pipeline — latency -45.3% (435->238ms), prompt tokens -48.7% (3,760->1,929), quality +1.86 points. E.g. a knowledge-base assistant answers "how long is the refund window?" with fact anchoring (zero-hop-like) while "why did churn spike after the price change?" gets top-down insight grounding — correct routing cuts roughly half the tokens without losing quality.
- Match retrieval depth to knowledge setting: sparse corpora (weakly linked docs) may benefit from deeper traversal (CS Complex-only +1.09 over Moderate), but on dense corpora Moderate-only beats Complex-only (+1.39-1.51) — excess depth hurts quality. E.g. measure the best mode per domain before freezing config; use dynamic routing instead of one global mode.
- Complex queries need insight-level navigation, not just fact retrieval: top-down insight edges + pi^-1 grounding yield causal chains with verifiable facts, while naive deep retrieval pulls 3,850 tangential tokens (e.g., irrelevant EGFR associations). E.g. a research assistant retrieves insight narratives first, then anchors to source documents, avoiding context dilution.

## Assumptions & Limitations
- Conditions: corpus must support dual-hypergraph construction (entities + higher-order factual hyperedges + insight mapping pi); fixed generation backbone + embedding model (GPT-4o-mini + text-embedding-3-small); gamma threshold calibratable on the query distribution.
- Authors admit: Intent Routing operates independently of the real-time graph structure — a Complex query in a structurally sparse domain may retrieve insufficient supporting facts via Top-Down Insight Grounding, requiring fallback to dense vector search; constructing the dual-hypergraph incurs upfront indexing costs (offline construction vs online inference efficiency trade-off).
- Not stated: evaluation uses only normalized LLM-as-a-Judge scores (0-100) — NO exact-match/F1 factual correctness and NO human evaluation, so "quality" is judge perception, not ground truth; routing classifier internals are thin (construction/accuracy not reported — only gamma sensitivity); three discrete categories + conservative fallback (continuous soft routing is future work); single backbone at T=0 — backbone generalization untested; Table 1 dataset statistics are mangled in the PDF text layer (per-cell attribution unreliable — corpus sizes unverifiable); ablation does not separate classifier contribution from operator contribution; the fallback-to-dense-vector path is not quantitatively evaluated.
