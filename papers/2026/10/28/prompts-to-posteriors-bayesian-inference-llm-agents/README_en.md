# [2610.29331] From Prompts to Posteriors: Can LLM Agents Perform Bayesian Inference in Context?

## Problem
- AI-scientist systems built on LLMs (large language models) must continuously update beliefs as evidence accumulates, for which Bayesian inference is the natural framework. Prior work ASSUMES LLMs cannot perform principled Bayesian belief updating in context, and therefore builds strict harnesses (e.g., BED-LLM) that fix large parts of the probabilistic model externally. The gap: this assumption had never been evaluated in a principled way — how badly do LLMs violate Bayes' rule, and which factors (native reasoning, code execution) close the gap?

## Contribution
- A principled evaluation framework along three progressive axes: (1) probabilistic coherence, probed via Dutch-Book constructions (equivalent to violations of Kolmogorov's axioms); (2) posterior fidelity, measured as KL divergence from a Bayesian oracle; (3) downstream task performance in adaptive experimental design, to determine whether non-Bayesian drift has practical consequences.
- ProteinWorld, a highly configurable synthetic environment mimicking protein-classification scientific discovery, procedurally generating a novel fictional world per instance (strictly out-of-distribution), with a simple version (closed-form likelihood) and a hard version (analytically intractable likelihood requiring Monte Carlo simulation).
- Evidence that LLMs violate Bayes' rule without reasoning, but modern reasoning models compute externally determined closed-form posteriors exactly, stay consistent over 10+ data points, and with code-execution tools correctly approximate analytically intractable posteriors — potentially rendering current belief-updating harnesses unnecessary.

## Method (core summary)
- Bayes' rule (Eq. 1): p_k(θ) := p(θ|h_1:k) ∝ p(y_k|θ,ξ_k)·p_{k-1}(θ) ∝ p_0(θ)·∏ p(y_i|θ,ξ_i). LLM-elicited probabilities p^LLM (verbalized or token-logprobs) are compared against the oracle posterior p^oracle.
- Dutch Book: a set of simultaneous bets from declared subjective probabilities that guarantees loss regardless of outcome. Three violation types are checked — extensionality (E), normalization (N), monotonicity (M) — 10 ForecastBench scenarios each (30 scenarios), under two elicitation settings: independent chats (cross-conversation) vs a single chat (within-dialogue).
- Sequential belief updating runs three trajectories: p^LLM (LLM updates beliefs AND chooses experiments), p^ora-pas (passive oracle applying Eq. 1 with the fixed prior and the LLM run's experiment outcomes), and p^ora-act (active oracle that also chooses experiments from its beliefs). Posterior fidelity uses forward KL(p^ora-pas ∥ p^LLM) — deliberately forward KL to discourage early discarding of still-valid hypotheses; p^LLM is clipped from below at 1e-6 and renormalized.
- Downstream scoring: mass placed on the true hypothesis {p_k(θ*)}, and the posterior-mass gap (Eq. 4) p^ora-act(θ*) − p^LLM(θ*), which is less influenced by environment hardness than absolute identification accuracy.
- 20Q: experiments are unrestricted Yes/No questions; Θ is all existing animals (infinite); the LLM maintains a dynamic subset Θ_k, assesses compatibility, and normalizes — inducing a uniform prior. The oracle uses the LLM's own likelihood assessments, so 20Q tests internal probabilistic consistency.
- ProteinWorld: Θ = 8 protein classes with 8-dimensional latent attribute vectors governed by randomized class-conditional distributions p(a|θ); 6 experiments with observation model p(y|a,ξ); likelihood p(y|θ,ξ) = ∫ p(y|a,ξ)p(a|θ)da (Eq. 5). 5 independent worlds × 8 classes (each class ground truth once) = 40 runs, T = 6.
- Models: coherence — Gemini-2.5-Pro, Gemma-4-31B-it, Qwen-2.5-32B-Instruct; sequential updating — Qwen-2.5-32B-Instruct, Phi-4, Gemma-4-31B-it, Gemma-4-26B-A4B-it, Qwen-3.6-35B-A3B (last three also with reasoning mode); ProteinWorld-hard — Gemini-2.5-Pro with native Python code execution.

## Key Findings
- Result 1 (coherence): cross-conversation Dutch-Bookable violation rates exceed 50% of the 30 scenarios for almost all model–constraint combinations; within a single dialogue they drop markedly — to 10% for Gemini and 1 of 30 scenarios for Gemma. Cross-conversation incoherence reflects the absence of a persistent common representation, not an inability to apply probability rules.
- Result 2 (no reasoning): KL divergence becomes large after only a few experiments in both 20Q and ProteinWorld-simple; downstream, LLM belief updates reduce final success rates by at least 30% versus the active oracle across all models and both environments; on 20Q weaker models collapse catastrophically to ~0% final accuracy; on ProteinWorld modern non-reasoning models often identify the most likely protein but assign too much or too little mass, while weaker models show no signal beyond random guessing.
- Result 3 (reasoning): on 20Q reasoning strongly reduces KL for all three models, with Gemma-4-31B-it achieving mostly consistent updates for up to 10 experiments; on ProteinWorld-simple modern reasoning models reach KL close to 0 regardless of experiment count, and Gemma-4-31B-it matches the oracle across the entire discovery process; errors are numerical slips, not conceptual failures; the correct posterior is typically re-verified over thousands of redundant tokens.
- Result 4 (tools): on ProteinWorld-hard, reasoning-only models recognize unprompted that the Eq. 5 marginalization is analytically intractable, yet proceed as if they could run a Monte Carlo procedure, reporting hallucinated simulation output or overly broad numerical approximations (high KL, degraded performance for Gemini-2.5-Pro). With native Python code execution, the model writes a numerically stable Monte Carlo estimator, driving KL divergence and the performance gap close to 0 — matching the oracle.
- Result 5 (harnesses): for modern reasoning LLMs, the structural harnesses of belief-updating frameworks such as BED-LLM may no longer be necessary — full belief updates performed by the LLM itself reach comparable downstream task performance.

## Actionable Insights
1. Elicit probabilities within a SINGLE dialogue: cross-conversation judgments are Dutch-bookable in >50% of scenarios versus 0–10% within-dialogue. Example: a risk-forecasting agent must gather all related probability judgments in one session rather than asking scattered questions across sessions and stitching results together.
2. Do NOT trust non-reasoning models for multi-step belief updating: they lose at least 30% success rate versus the oracle. Example: any monitoring agent that accumulates evidence over many turns should force a reasoning mode plus a code-execution tool for posterior computation instead of letting the model "calculate mentally".
3. Reasoning models know when simulation is needed but will HALLUCINATE without tools: they self-diagnose intractable posteriors yet fabricate Monte Carlo output. Example: when an agent analyzes risk with complex likelihoods, provide a real Python sandbox and audit that the produced code contains a stable estimator.
4. Replace strict harnesses with an explicit belief state: BED-LLM-style external fixing can be dropped for modern reasoning models — but keep a persisted belief state for cross-conversation coherence and human auditability. Example: a preliminary medical triage agent stores a per-hypothesis posterior table in a database and reloads it each session instead of re-eliciting from scratch.

## Assumptions & Limitations
- Conditions for the method to work: the prior p0 is fixed externally; the likelihood model is fully specified (20Q uses the LLM's own likelihood judgments as the oracle proxy; ProteinWorld has complete mathematical specification); 20Q necessarily deviates from strict Bayesian updating via a dynamic hypothesis subset Θ_k and an induced uniform prior because its hypothesis space is infinite.
- Paper-stated: the 20Q oracle measures internal probabilistic consistency (based on the LLM's own likelihoods), not truth about the world; future work is to build concrete less-restrictive harnesses that still carry an explicit belief state.
- Not stated but observed: all environments are synthetic/procedural (ProteinWorld uses fictional terminology) — no validation on real scientific discovery data; non-reasoning comparisons use a fixed compute budget of exactly the tokens needed to output probabilities; the forward-KL choice biases toward mass coverage over precision; only 5–6 models were tested, so "modern reasoning model" results may not generalize to smaller/weaker models.
